# Prefix Tree (Trie)

A Java implementation of a prefix tree (Trie), developed as part of a university programming assignment.

## Overview

The project demonstrates the implementation of the Trie data structure for storing and processing strings. It explores tree-based data structures, prefix operations and basic algorithmic concepts.

## Technologies

- Java

## Project Structure

- `Trie.java` — prefix tree implementation
- `Graph.java` — graph data structure
- `MyList.java` — custom list implementation
- `Main.java` — application entry point
